## 4. 执行方式

### 4.1 环境准备

```cmd
cd "d:\Program Files\pythen12\py_tode\xhcs\xh_api_auto"
copy .env.example .env
REM 编辑 .env：配置 GATEWAY_URL 和 TEST_TOKEN

pip install -r requirements.txt
```

### 4.2 执行命令

| 场景 | 命令 |
|------|------|
| 全量执行 | `pytest` |
| 仅冒烟（P0 用例） | `pytest -m smoke` |
| 仅商品服务 | `pytest -m product` |
| 仅秒杀服务 | `pytest -m seckill` |
| 仅公开接口 | `pytest -m public` |
| 仅反向用例 | `pytest -m negative` |
| 指定测试环境 + 网关 | `pytest --env test --gateway http://10.0.0.1:8080` |
| 多进程并发 | `pytest -n 4`（需 pytest-xdist） |

### 4.3 生成 Allure 报告

```cmd
REM 运行完 pytest 后（结果自动写入 report/allure-results）：
allure generate report/allure-results -o report/allure-report --clean
allure open report/allure-report
```

报告包含：
- Epic / Feature / Story 三层分类
- 用例严重级（Blocker/Critical/Normal/Minor）
- 每个步骤的 Request / Response JSON 附件
- 失败用例 Failure Info 附件
- 环境信息（GATEWAY_URL / Environment / Python / RunTime）
- 重试机制（失败自动重试 1 次，间隔 2s）
